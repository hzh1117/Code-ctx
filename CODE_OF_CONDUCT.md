# Code of Conduct / 行为准则

## 中文

### 我们的承诺

我们希望 Code-ctx 成为一个实用、尊重他人、对开发者有帮助的开源项目。贡献者和维护者都应清晰沟通，并尊重他人。

### 推荐行为

- 保持尊重和建设性。
- 讨论聚焦在 issue 或 pull request 本身。
- 默认善意，但对技术问题保持直接。
- 专业地接受反馈。

### 不可接受的行为

- 骚扰、侮辱或歧视性语言。
- 人身攻击或反复干扰讨论。
- 未经允许公开他人隐私信息。
- 引入或鼓励使用泄露的密钥、凭据或私有代码。

### 执行方式

维护者可以编辑、隐藏或删除违反本准则的评论、issue、pull request 或贡献。重复或严重违规可能导致被禁止参与项目。

### 报告

如果需要报告行为问题，且问题涉及安全或隐私数据，请使用私有安全报告。其他情况可通过仓库所有者主页联系维护者。

## English

### Our Pledge

We want Code-ctx to be a practical, respectful, and useful project for developers. Contributors and maintainers are expected to communicate clearly and treat others with respect.

### Expected Behavior

- Be respectful and constructive.
- Keep discussion focused on the issue or pull request.
- Assume good intent, but be direct about technical problems.
- Accept feedback professionally.

### Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Personal attacks or repeated disruptive comments.
- Publishing private information without permission.
- Introducing or encouraging the use of leaked secrets, credentials, or private code.

### Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that violate this code of conduct. Repeated or serious violations may result in a ban from the project.

### Reporting

If you need to report a conduct issue, open a private security advisory if the issue involves security or private data. Otherwise, contact the maintainers through the repository owner profile.
